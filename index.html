Open Banking • AISP

Bank of Ireland Sandbox

Local offline simulator of Bank of Ireland Account Information Services APIs.
No certificates • No TPP registration • Pure Python

View on GitHub General Sandboxes →

Quick Start

localhost:3004
  • python mock_server.py --port 3004
  • or docker compose up --build
  • Use Authorization: Bearer sandbox-token for instant access

What is included

  • mock_server.py — pure-Python Open Banking AISP simulator
  • sdk/ — clean Python client (BankOfIrelandClient)
  • data/seed.json — realistic IE (EUR) + UK (GBP) test accounts
  • Dockerfile + docker-compose.yml

Main endpoints

  • POST /oauth/as/token.oauth2
  • POST /account-access-consents
  • GET /accounts
  • GET /accounts/{id}/balances
  • GET /accounts/{id}/transactions
The real Bank of Ireland sandbox requires TPP registration, SSA and eIDAS certificates.
This local version needs none of that — perfect for offline development and CI.
